# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in DebugToggle, please disclose it responsibly.

- **Private Reporting:** Open a [Security Advisory](https://github.com/jinto-ag/debug-toggle/security/advisories/new) on GitHub.
- **In-App Reporting:** Tap **Report Security Vulnerability** within the DebugToggle app settings to pre-fill device diagnostics and open the reporting form.

### Response SLA

- Initial acknowledgement: within 48 hours.
- Status update and assessment: within 5 business days.

Please do not open public GitHub issues for security vulnerabilities until a patch is available.
